# 🛒 Sistema de Ventas

**Descripción:**
Sistema de Ventas es un proyecto desarrollado en **MySQL** que implementa una base de datos relacional para un sistema de ventas.

El proyecto fue creado con el objetivo de aplicar conceptos de modelado de bases de datos, relaciones entre tablas y consultas SQL para la gestión de clientes, productos, empleados y ventas.

**Funcionalidades:**

- Creación de la base de datos
- Diseño de tablas relacionadas
- Implementación de llaves primarias y foráneas
- Gestión de clientes
- Gestión de productos
- Gestión de ventas
- Gestión de empleados
- Consultas SQL utilizando JOIN
- Consultas con subconsultas
- Uso de funciones de agregación (SUM, COUNT, MAX)
- Consultas con GROUP BY, HAVING y ORDER BY
  
**Tecnologías utilizadas:**

- MySQL
- SQL
